# Mak McKinney – Software Engineering Portfolio

Welcome to my personal software engineering portfolio, built with **React**, **Tailwind CSS**, **Framer Motion**, and **GSAP**. This portfolio showcases my projects, experience, and background in computer engineering, embedded systems, and creative development.

**Live Site**: [makmckinney.com](https://www.makmckinney.com)

## ✨ Features

- 📌 Custom scrapbook-style landing page
- 🧩 Modular project system with search, filter, and detailed views
- 📱 Fully responsive and animated using Framer Motion + GSAP
- 🎨 Tailwind-based theming with custom color palette
- ⚙️ React Router for seamless navigation

## 🧱 Stack

- **React** (Vite)
- **Tailwind CSS**
- **Framer Motion**
- **GSAP**
- **Netlify** (Deployment)
